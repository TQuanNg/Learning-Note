## Setup
In AndroidManifest:
```
<provider  
	android:name="androidx.core.content.FileProvider"  
	android:authorities="${applicationId}.provider"  
	android:exported="false"  
	android:grantUriPermissions="true">  
	  
	<meta-data  
	android:name="android.support.FILE_PROVIDER_PATHS"  
	android:resource="@xml/file_paths" />  
</provider>
```

In res/xml/file_paths.xml: tells Android files inside cache Dir can be shared through FileProvider
```
<paths> 
   <cache-path
        name="camera_images"
        path="."
 /></paths>
```
## URI
When taking picture, you need to create an actual file that the camera app can write into.
URI: is the secure location where Anrdoid save captured image.
Android requires you to provide secure '**Uri**' through FileProvider

`import android.net.Uri`

```
fun createImageUri(context: Context): Uri {  
	val image = File(  
		context.cacheDir,  
		"camera_photo_${System.currentTimeMillis()}.jpg"  
	)  
	  
	return FileProvider.getUriForFile(  
		context,  
		"${context.packageName}.provider",  
		image  
	)  
}
-> result: content://com.example.carewise.provider/cache/camera_photo_123.jpg
```
⚠️⚠️⚠️: File path from FileProvider - and file/paths.xml **MUST** match
### Flow
Request CAMERA permission  
↓
Permission granted  
↓
Create File  
↓  
Convert File -> Uri  
↓  
Launch Camera  
↓  
Camera saves image into File  
↓  
You receive Uri back

#### 💡FileProvider?
Before, real file path is used to pass around or save photo like
`/storage/emulated/0/Pictures/receipt.jpg`
⚠️ But that's a security problem. Apps learn your internal file structure and can access files they shouldn't have

**The solution: FileProvider**: Android gives another app a temporary, controlled URI generated by FileProvider:
`content://com.example.carewise.provider/receipt.jpg`
