
# 🚀 Navigation (Most Used)

| Action                           | Shortcut                        |
| -------------------------------- | ------------------------------- |
| Search everywhere                | **Shift Shift**                 |
| Find class                       | **Ctrl + N**                    |
| Find file                        | **Ctrl + Shift + N**            |
| Find symbol (function, variable) | **Ctrl + Alt + Shift + N**      |
| Recent files                     | **Ctrl + E**                    |
| Recent locations                 | **Ctrl + Shift + E**            |
| Go to declaration                | **Ctrl + B** / **Ctrl + Click** |
| Go to implementation             | **Ctrl + Alt + B**              |
| Go to super class/interface      | **Ctrl + U**                    |
| Back                             | **Ctrl + Alt + Left**           |
| Forward                          | **Ctrl + Alt + Right**          |

# ⚡ Refactoring (You'll use these A LOT)

| Action            | Shortcut           |
| ----------------- | ------------------ |
| Rename            | **Shift + F6**     |

| Extract parameter | **Ctrl + Alt + P** |
| Extract function  | **Ctrl + Alt + M** |
| Change signature  | **Ctrl + F6**      |
| Safe delete       | **Alt + Delete**   |

Select Smarter (expand selection): **Ctrl + W**

🔥 Kotlin Tricks

Complete code: **Ctrl + Space**
Smart completion: **Ctrl + Shift + Space**
